Atmosphere

On AT Protocol

Whole Body Cookbook is meant to live in the Atmosphere, not as a silo. The first version uses ordinary Bluesky posts so anything you pin is already visible in the main app. A custom lexicon rides alongside for apps that know how to read a body.

1. Dual-write

You publish an app.bsky.feed.post with hashtags #WholeBodyCookbook and a region tag such as #wbc-heart. That post is a first-class Bluesky object.

Optionally you also write app.wholebodycookbook.pin into your own repo. Other Atmosphere apps can index the collection without scraping hashtags.

2. Lexicons in this repo

lexicons/app.wholebodycookbook.pin.json
lexicons/app.wholebodycookbook.recipe.json

To publish the lexicon under a real NSID you will want a domain you control and a DNS TXT proof pointing the namespace at your DID. Until then the schema is a proposal the site already understands.

3. What comes next

OAuth sign-in (Statusphere pattern) so the site can write the custom record for you. A Jetstream consumer. A custom Bluesky feed. Later a 3D BodyParts3D figure with the same region ids.
