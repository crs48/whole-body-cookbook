# Claude Design — Whole Body Cookbook

You are designing the visual system and high-fidelity UI for **Whole Body Cookbook**, an open-source AT Protocol atlas. People pin Bluesky posts to rooms of a body. Meridians, the autonomic nervous system, conditions, and folk maps share one figure.

This file is the design brief. Do not write production code here. Produce screens, components, and a visual language that a TypeScript rebuild can implement in Tailwind.
